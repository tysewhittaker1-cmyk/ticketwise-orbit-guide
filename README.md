# Ticketwise Orbit Guide

My team wants to build a ServiceNow AI agent support that can read tickets from end users,  complete easier, routine tickets, and give proposed recommendations for more complex tickets. It will send tickets to the appropriate analytics team.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://ticketwise-orbit-guide.lovable.app
